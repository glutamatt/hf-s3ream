Run Jobs that S3ream your data into Hugging Face Storage Bucket

Point it at an s3:// prefix and a destination bucket — the copy fans out on HF Jobs, the same infra your models live on. No CLI, no local compute. Your AWS keys go only into the Job’s encrypted secrets.

Jobs and the bucket are created under your account (billed to you). Scopes: jobs, write-repos, read-billing (shows what the copy costs).

Copy

S3 requests are sent unsigned (as with aws s3 --no-sign-request), so the source must allow anonymous reads — the AWS Open Data registry lists such buckets. No AWS credentials are sent to the Job.

Advanced

Analyze fills these in for you — override only if you know why.

🔒 Your AWS keys never touch a server — they go from your browser straight into the Job’s encrypted secrets. Prefer a scoped, read-only key.
